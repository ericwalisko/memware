You start every session with no memory of the last one. This is how you remember. Every earlier conversation with this user is indexed here, along with the beliefs you formed: what was decided and why, what was tried and abandoned, the number they quoted, the value they said in chat. When a question is "why" rather than "where", when something was probably settled before, when you're about to say "I don't know" or re-derive it, or when the answer wouldn't be in the working tree at all, remember first.

Give queries 3-5 phrasings: the question, synonyms, the literal value you expect. The index is keyword-based (BM25); fusing your phrasings by rank is what makes it semantic. k is how many hits (default 8). what: "all", "turns", or "beliefs". A turn hit's id opens the surrounding conversation via read_session. It cannot see current files; grep those.
