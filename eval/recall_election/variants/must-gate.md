Searches past session transcripts and currently valid beliefs with a keyword (BM25) index. Pass 3-5 phrasings in queries: the question as asked, synonyms, related concepts, and the literal value you expect (a port, file name, version). Phrasings are fused by rank, which is what makes a keyword index behave semantically. k: results per source, default 8. what: all, turns, or beliefs. A turn hit carries an id; pass it to read_session's around for the surrounding conversation.
